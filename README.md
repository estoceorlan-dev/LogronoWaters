# AquaFlow

AquaFlow is a React dashboard for managing a water refilling station. It provides a central view for daily operations, including orders, inventory, customer records, and system settings.

## Tech Stack

- React 19
- Vite
- React Router
- Tailwind CSS
- Recharts
- Lucide React

## Getting Started

Requirements: Node.js 22 or newer and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

## Available Scripts

```bash
npm run dev      # Start the development server
npm run build    # Create a production build
npm run preview  # Preview the production build locally
npm run lint     # Run Oxlint
```

## Project Structure

- `src/components/` shared layout and UI components
- `src/pages/` dashboard, orders, and inventory views
- `src/assets/` application assets
- `public/` static files served as-is
